# Day - 06 Cisco Networking Basics and Packet Tracer

## How Data Moves Across a Network

Today, I learned the basics of how data moves across a network, including IP addresses, network layers, and how devices communicate. I also learned that a switch connects devices within a local network.

In Packet Tracer, I practiced connecting two PCs to a switch and assigning IP addresses. I learned that ARP finds the destination device's MAC address before the ICMP ping tests connectivity.

## Three Things I Learned

IP addresses identify devices on a network.

Switches help devices communicate within a local network.

ARP resolves IP addresses to MAC addresses before communication when needed.
