# Day 17 - Project 1, Session 3 — Network Scanning, Wireshark, and Web Attacks

## What I Did
- Started Kali Linux and my target VM and checked network connectivity.
- Used Nmap to scan my target VM and identify open ports and services.
- Captured and analyzed network traffic using Wireshark.
- Practiced SQL Injection, Reflected XSS, Stored XSS, and Brute Force in DVWA.
- Used Burp Suite to inspect HTTP requests and compare login responses.
- Documented my findings and organized screenshots for Project 1.

## Attack That Surprised Me Most
Stored XSS surprised me most because I learned that unsafe input can be saved on a website and trigger JavaScript when someone visits the page later.

## Hardest Part
Brute Force was the hardest part because I found it difficult to identify potentially successful login attempts in Burp Intruder. I learned to compare response lengths and messages to investigate the results.

## What I Learned
- How Nmap identifies open ports and services on a target machine.
- How Wireshark captures and analyzes network traffic.
- How common web vulnerabilities work and how Burp Suite helps inspect HTTP requests and responses.
- How developers can prevent SQL Injection, XSS, and brute-force attacks using secure coding practices and login protections.
